# Source history after the repository split

This repository was extracted from `DevilTea/deviltea-labs` after the initial `@deviltea/widget-core@0.0.1` and `@deviltea/widget-vue@0.0.1` releases.

The extraction preserved the Git history for:

- `packages/widget/core` → `packages/core`
- `packages/widget/vue` → `packages/vue`
- `apps/widget-lab` → `apps/lab`
- the Widget API conventions and package documentation

The release tags `widget-core@0.0.1` and `widget-vue@0.0.1` are preserved.

Historical architectural decision logs were not migrated as GitHub Issues. References such as `issue #10`, `#13`, `#25`–`#30`, `#54`, and `#60` in migrated source refer to the original `DevilTea/deviltea-labs` issue tracker unless the reference explicitly names `DevilTea/widget`.
