# Migrating from 0.1 to 0.2

> **Pending: not released yet.** This page records what the next release will change, so that it is not

> are `0.x`, a breaking TypeScript change bumps the minor version of all three packages

## Who needs to do what

| You are | Do |
| --- | --- |
| An application or host that only builds Systems and runs Runtimes | Nothing; `@deviltea/widget-core` and `@deviltea/widget-vue` have no change in this line so far. Upgrade the three packages together |
| An Inspector integrator that switches on a member's `type` | [Method members in the Inspector protocol](#method-members-in-the-inspector-protocol) |

## Method members in the Inspector protocol

Inspector protocol `0.5` adds each Method's current diagnostic snapshot to the Runtime widget snapshot, and
`runtime.subscribeMember` / `runtime.memberChanged` carry it. It is a negotiated capability: a peer negotiated at an
older minor sees exactly the `0.4` wire shapes, so no peer needs to change to keep working. See the
[Inspector protocol versions](../packages/widget-inspector#two-version-axes).

- **Detect:** a compile error in code that switches exhaustively on `InspectorRuntimeMemberSnapshot['type']` or
  `InspectorMemberRef['type']`. Both unions gain `'method'` (`InspectorRuntimeMethodSnapshot` joins the snapshot
  union), so a `switch` with no `default` and a `never` check no longer type-checks. Nothing changes at run time for a
  consumer that never receives a Method member, which a peer negotiated below `0.5` never does.
- **Find:** `rg "InspectorRuntimeMemberSnapshot|InspectorMemberRef|InspectorRuntimeWidgetSnapshot"`.
- **Do:** add a `'method'` branch (the member has `name` and `diagnostics`, the same `InspectorRuntimeDiagnostic` list a
  failed Property carries), or ignore it in a `default`. A client that accepts Method members only from a `0.5`
  or newer envelope needs no other change; subscribing to a Method needs a negotiated minor of `0.5` or newer, and an
  older Agent answers `invalid-params`.
